# アジアハンドボール 攻守対照表（2022–2026）

アジア選手権（2022 女子 / 2024 男女 / 2026 男子）とアジア競技大会 2026 の公式リザルト PDF から集計した、チームと選手の攻守の比較ダッシュボードです。男子と女子は別ページです。

- チーム: 攻撃・守備・ポジション別（50 回あたり、ターンオーバー率、防御率、GK など）
- 選手: CP と GK、行をクリックして 3 大会の推移グラフ
- 推移: 国ごとの大会間グラフ（複数の国を重ねて比較）
- 散布図: 攻撃回数あたり得点 × 守備回数あたり失点（k-means クラスター分析）
- 因子分析: 攻撃・守備の因子分析（大会の選択を反映）

## 指標の定義

- 攻撃回数 = シュート数 + ターンオーバー数（TO + TF）。守備回数は相手の攻撃回数。公式の Number of Attacks とは、オフェンスリバウンドによる再シュートの分だけ数が合いません。
- ポジションは紙面の区分（6m / ウイング / 9m / 速攻 / ブレイクスルー / 7m）で、選手個人のポジションではありません。
- 欠損は 0 ではなく「–」です。

## 構成

静的なページだけです（ビルド不要）。`data/M.js` と `data/W.js` が集計済みのデータで、元データ（PDF）とパーサは別のリポジトリにあります。

ローカルで見るには、このフォルダで `python3 -m http.server` を実行して `http://localhost:8000/` を開いてください。
